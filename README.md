JadevOS Computers
JadevOS Computers 1.0 BETA 4 is a real distribution based on Debian GNU/Linux 13, featuring the Linux kernel and GNOME as its default desktop environment, customized with the MacTahoe dark theme, orange icons, a bottom Dash to Dock, and a translucent panel. Carbon DSK is retained as an alternative session. It includes Files (the proprietary dual-pane file manager), Software Updater (available from the menu; it does not open automatically), GNOME Terminal, Archive Manager, Firefox ESR, HyperBrowser with Google as its homepage, Nautilus, and Carbon DSK. GNOME Settings, Tweaks, and Extensions allow for interface customization. Carbon DSK utilizes Openbox and Picom as its window manager and compositor, featuring its own panel, dock, launcher, workspaces, and controls. The system's codename is kiwi. The boot screen and Plymouth animation exclusively use JadevOS branding. The Live session automatically logs into a temporary random account named jadevos-session-*; it never creates an account named live. Upon installation, the account created during the installation wizard is used. It activates compressed zRAM memory to improve responsiveness under low RAM conditions, without disabling visual effects or removing applications. The boot menu is minimalist, in English, and offers Start JadevOS and Boot into Safe Mode over a black background. The startup animation and the installer use the JadevOS branding; the ISO is built for x86-64 machines with BIOS booting.
Building the ISO on Windows
Requirements: Windows with WSL 2 installed. An Ubuntu 24.04 distribution within WSL. If your distribution has a different name, you can specify JADEVOS_WSL_DISTRO before running the builder. An internet connection and sufficient free disk space to download packages and generate the image are also required.
From PowerShell, inside the project folder:
powershell
python build.py
Usa el código con precaución.
The builder installs any missing Debian Live tools inside Ubuntu WSL and saves the ISO to dist\jadevos-tahoe.iso, overwriting the existing image on every compilation. The first build takes longer because it downloads Debian and the applications. It does not require NASM nor does it replace the Windows operating system.
To explicitly use a fixed path instead of the default unique name:
powershell
python build.py --output dist\jadevos-prueba.iso
Usa el código con precaución.
Testing and Installing
On a compatible x86-64 machine, prepare an empty disk of 25 GB or more and an internet connection. Boot the newly generated ISO in dist using BIOS firmware; this development ISO does not support UEFI yet.
The default session automatically starts GNOME with the MacTahoe dark theme, orange MacTahoe icons, a GTK/libadwaita appearance, a floating and auto-hiding bottom dock, a translucent panel, and window buttons on the left. Carbon DSK remains available as an alternative session in SDDM. System configuration is managed via GNOME Settings and GNOME Tweaks. It includes Files, Software Updater, GNOME Terminal, Firefox ESR, a camera app (Cheese), and the Parole media player. The file manager allows copying, moving, renaming, and sending items to the trash. The camera requires a compatible device, and Parole plays local music files.
The initial background is JadevOS Computers BETA 4. The wallpaper selection is available under GNOME Settings → Appearance; Debian wallpapers have been removed from this selector and from the system image. The JadevOS system information displays the Linux kernel series detected at boot, for example, 6.12.
In Live mode, SDDM automatically opens the graphical session with a temporary account using a random name prefixed with jadevos-session-; an account named live is never created. On the installed system, log in using the account created during installation.
To preserve your files and changes after powering off the machine, open the JadevOS Installer and use the graphical wizard. Choose only the empty disk prepared for JadevOS; installing or partitioning a disk can erase its data.
The initial language is English (United States). You can change it to Spanish from GNOME Settings → Region & Language; select Spanish and log out and back in to apply the language change. The initial keyboard layout is US and can also be changed from GNOME Settings → Keyboard.
The Live session is useful for testing the desktop, but its changes will not persist after shutting down. Its temporary account receives a random name and uses the password live for administrative tasks. This does not affect the account created during installation. The installer requests graphical authorization before opening; type the temporary password live when the permissions dialog appears.
JadevOS Updater
The ISO includes Software Updater, a desktop application in English that checks for versions published on jamillansantiago/updates, downloads signed OTA bundles, and requests administrator authentication via PolicyKit before installing packages. The updater verifies the Ed25519 signature both before offering the bundle and from within the privileged installer. Installations do not download additional dependencies or remove packages. Software Updater only opens when launched by the user; it does not run at session startup. The update repository must publish the .tar.gz bundle and its .sig signature following the updater's guide. Until signed releases are published, the application will clearly indicate that no updates are available; the ISO includes the client, not a dummy OTA update.
Tahoe Theme
The GNOME appearance takes inspiration from the Tahoe video and utilizes the MacTahoe GTK Theme and Icon Theme by vinceliuice, featuring a dark orange variant, the GTK theme for libadwaita, User Themes, Dash to Dock, and Blur my Shell. The builder locks specific revisions for both themes and verifies their SHA-256 checksums before incorporating them. Fonts and their licenses are included in /usr/share/doc/jadevos/mactahoe within the system.
Current Scope
This is an initial development distribution based on software from the Debian project; it is not a kernel developed from scratch. It is targeted at x86-64 machines with BIOS and has not yet been validated on physical hardware. The ISO does not boot with UEFI yet, and it does not include Secure Boot or guaranteed support for all hardware. The internet connection depends on the network available on the machine.
The files jadevos.py, boot.asm, and kernel.asm are older educational prototypes. build_bios.py retains the generator for those demonstration images; it does not create the complete system. Use python build.py to generate the actual JadevOS ISO.
